# Minor Projects – To-Do App & Notes App

## About the Project

This project is a simple web application built using React. It contains a To-Do App to manage daily tasks and a Notes App to save important thoughts and information.

The project was created to practice React concepts and learn how to build interactive web applications.

## Features

### To-Do App
- Add new tasks
- Mark tasks as completed or pending
- Edit and delete tasks
- Filter tasks by status
- View total, pending, and completed task counts
- Save tasks using Local Storage

### Notes App
- Create notes with a title and description
- Edit existing notes
- Delete notes
- Search notes by title or content
- Save notes using Local Storage

## Technologies Used

- HTML5
- CSS3
- JavaScript
- React
- Vite
- Browser Local Storage
- Git and GitHub

## Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Open the Project Folder

```bash
cd minor-project-04
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL shown in your terminal to use the application.
